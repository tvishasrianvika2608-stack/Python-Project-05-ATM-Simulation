# Project 5: ATM Transaction Sequence Simulation

## Problem Description
This project simulates ATM transactions by processing deposits and withdrawals. It maintains the account balance, enforces withdrawal limits, rejects invalid transactions, and generates a transaction summary showing total deposits, total withdrawals, rejected transactions, and the final account balance.

## Programming Language
Python

## Concepts Used
- Variables and data types
- Lists and tuples
- For loops
- Conditional statements (if, elif, else)
- Arithmetic operators
- User input and output

## Files Included
- `Question_05_ATM_Simulation.py` – Python source code
- `Screenshots/` – Code and output screenshots

## How to Run
1. Download the Python file.
2. Open it using Python or VS Code.
3. Run the program.
4. Enter the initial account balance.
5. Enter the transaction type and amount for each transaction.
6. View the final ATM transaction summary.

## Conclusion
The program successfully simulates ATM transactions, maintains the account balance, validates deposits and withdrawals, rejects invalid transactions, and displays a detailed transaction summary.
